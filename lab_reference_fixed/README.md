# Лабораторная: исправленная версия присланного образца

Все исходники и заголовки лежат в этой папке. Откройте её в VS Code.
Добавлять файлы из других версий лабораторной в сборку не нужно.

В терминале с настроенным компилятором Visual Studio:

```text
cl /EHsc /std:c++17 /utf-8 main.cpp Manager.cpp Utilis.cpp pipe.cpp CompressorStation.cpp /Fe:program.exe
.\program.exe
```

- `main.cpp` только вызывает `runProgram()`. Меню и пункт 4 «Поиск и управление объектами» находятся в `Manager.cpp`.
- `std::cin >> newPipe` и `std::cin >> newCs` вызывают перегруженный ввод. `operator<<` выводит поля объекта для пользователя; старые методы `print()` используют его.
- `Logger` перенаправляет `std::clog` в `log.txt`. В каждой записи есть время, файл, строка, функция и событие. При изменении ремонта или числа работающих цехов записываются ID и значения до и после.
- Сохранены исходное меню 0–6, фильтры, действия над всеми найденными объектами и формат файла данных. Сохранение и загрузка по-прежнему идут через `saveToFile()` и `loadFromFile()`.

В исходном образце поиск по названию проверяет начало названия, а поиск КС по проценту — нижний порог. Эти правила сохранены.
